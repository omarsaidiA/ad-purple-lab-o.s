# Captures

Preuves référencées par les write-ups et le rapport.

Nommage : `<scénario>-<étape>-<description>.png`, par exemple
`02-trace-4769-rc4.png` ou `04-correction-certipy-find.png`.

Avant de commiter une capture, je vérifie :

- qu'aucune empreinte, aucun ticket et aucune clé privée n'apparaît en entier
  (les tronquer ou les flouter) ;
- qu'aucun mot de passe du lab n'est lisible ;
- que seules des adresses du lab (10.10.10.0/24) et des noms en `lab.internal`
  apparaissent.
